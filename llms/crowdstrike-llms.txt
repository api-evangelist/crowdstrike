## Authentication

All API access requires OAuth2 credentials (client_id and client_secret) created in the Falcon console under Support and resources > API Clients & Keys. Tokens expire after 30 minutes. Base URLs vary by cloud region: us-1 (api.crowdstrike.com), us-2 (api.us-2.crowdstrike.com), eu-1 (api.eu-1.crowdstrike.com), us-gov-1 (api.laggar.gcw.crowdstrike.com).
